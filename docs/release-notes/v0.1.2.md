# App Depot Client v0.1.2

## Fixes

- Fixed the built-in updater's handling of GitHub release-asset redirects. It now follows approved HTTPS GitHub redirects to retrieve the checksum and AppImage instead of treating the redirect response as asset content.
- Unexpected response types now produce a clear update error. Release asset names, GitHub's published SHA-256 digest and the checksum asset must still agree before an update can be staged.

## Compatibility and upgrade

This maintenance release retains the Linux x86_64 AppImage, `io.github.viktorliho.AppDepot.desktop` identity, Gear Lever integration metadata and stable AppImage update information. It does not change the local library schema, `~/.appdepot` data, Server profiles or credentials.

The published v0.1.0 and v0.1.1 AppImages contain the redirect defect and cannot complete their built-in update check. To move from either version to v0.1.2, download the official AppImage and `.sha256`, verify them with `sha256sum -c`, and replace the existing integrated AppImage through Gear Lever without creating a second application entry. The built-in updater is available for later stable releases from v0.1.2 onward; this release does not prove a future live update has succeeded.
