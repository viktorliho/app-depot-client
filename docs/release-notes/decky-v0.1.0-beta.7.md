## App Depot Decky maintenance release

- **Settings & About** shows the installed Decky version, the official GitHub Releases link and diagnostics.
- Install and update through the official single-file Desktop Mode installer. Gaming Mode update checks and preview downloads have been retired.
- Steam shortcuts, artwork, native First Play, offline launch and local Uninstall remain available.

Close running games, download this release's `AppDepot-Decky-Installer.desktop`, then permit execution and run it in SteamOS Desktop Mode. It resumes interrupted downloads, checks the SHA-256 of this release's ZIP, validates the archive and installs the plugin. Return to Gaming Mode and check **Settings & About** for version 0.1.0-beta.7. [Manual update guide](https://github.com/viktorliho/app-depot-client/blob/4545573b87b0386749c6e881bcddb64555914832/docs/STEAMOS_DECKY.md#manual-installation-and-updates)
