# App Depot Desktop v0.1.5

Linux x86-64 and Windows x64 share the Desktop workflow for installing applications from a Standard InstallationManifestV1 plan. Desktop shows the resolved components and prerequisites before installation. Existing Legacy File and Tree applications remain supported.

Windows x64 can launch declared x86 and x64 applications. Windows prerequisites run in declaration order with their original working directories and supporting files. When an installer requires elevation, Windows presents the UAC prompt.

After a failure or cancellation, authorize a retry to resume the same installation. Core reuses recorded successful steps bound to the same generation and pinned plan. It can run an embedded installer from an intact application directory or reuse a verified workspace for consecutive steps from a separate Artifact. Changed source layouts are rebuilt as needed.

## Upgrade compatibility

Upgrading from v0.1.4 preserves installed applications, profiles, cached resources and installation state. The SQLite library migrates from schema 5 to schema 8. This migration is forward-only. Desktop v0.1.4 cannot directly open a migrated schema 8 library.

## Downloads and platform support

- Linux x86-64 uses the AppImage, its SHA-256 checksum and zsync metadata. Native execution of third-party prerequisites is available on Windows.
- Windows x64 uses the per-user Inno Setup installer. Verify it against SHA256SUMS. Setup is unsigned and may trigger a SmartScreen warning.
