# App Depot Desktop v0.2.0

Linux x86-64 can install and launch declared Windows applications with an existing Wine or Steam Proton runtime. Select the runtime in Desktop. App Depot uses a persistent application prefix for both prerequisites and the game. With Proton, it resolves the associated Steam Linux Runtime from the local Steam installation. Install and maintain compatibility runtimes separately.

On Windows x64, installation retries handle transient file sharing conflicts. Interrupted downloads and unpublished installations can recover. If a verified Tree member is damaged, Core can rebuild it from verified staging or fetch the affected member again. Windows publication uses handle-relative renames within the target directory.

## Tested configurations and limits

The owner confirmed Overlord II installation and gameplay on Windows 11 and on CachyOS. The CachyOS test used Steam Proton Experimental. The Steam Deck configuration was accepted separately through the Decky plugin. Compatibility depends on the application declarations, prerequisites and selected runtime. Some prerequisite installers require interaction.

Download the Linux x86-64 AppImage with its checksum and zsync metadata, or use the Windows x64 per-user installer. `SHA256SUMS` contains the Windows installer checksum. The Windows installer is unsigned and may trigger SmartScreen.
