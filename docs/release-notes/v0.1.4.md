# App Depot Desktop v0.1.4

This is the first unified Desktop release for Linux x86-64 and Windows x64.

## Downloads

- Linux x86-64 uses `AppDepot-0.1.4-x86_64.AppImage`. The release includes its SHA-256 checksum and zsync metadata.
- Windows x64 uses `AppDepot-Desktop-Windows-x64-Setup.exe`. Setup installs per user and adds a Start menu shortcut. The release includes `SHA256SUMS`.

## What's new

- Windows Desktop shares the Linux Desktop interface and Rust core. It can browse an App Depot Server, download and install supported File and Tree artifacts, verify them offline and launch declared Windows x64 applications.
- Windows tracks managed applications after Desktop closes. Safe local removal of verified installations blocks while managed occupancy is active or uncertain, or when ownership or integrity cannot be established.
- **Settings → Updates & about** discovers the same stable release on both platforms. Linux keeps the AppImage update path. Windows verifies the installer, asks for confirmation, waits for managed applications to exit and relaunches Desktop after successful Setup.

## Upgrade and limitations

Official Linux v0.1.3 AppImages can discover v0.1.4 after this complete release becomes GitHub Latest. Windows users installing Desktop for the first time should start with Setup. Desktop updates preserve the local library, installed applications, profiles and settings. No Server upgrade is required.

Windows 11 x64 is the primary validated Windows platform. Windows 10 x64 build 19041 and newer can run Setup. Basic installation, startup and catalog access were verified on physical Windows 10 using RC2. The full update lifecycle was verified on Windows 11. Older Windows Server 2022 runners showed NTFS sharing violations in File and Tree tests.

Windows Repair and automatic rollback of a failed Windows Desktop update are unavailable. Windows Setup is unsigned and may show a publisher or SmartScreen warning. SteamOS Decky has its own release channel.
