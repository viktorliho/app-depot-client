# App Depot Client v0.1.1

## Fixes

- Fixed interactive edge and corner resizing of the custom Linux desktop window.
- Kept the App Depot titlebar, minimum window size, and minimize, maximize and restore controls.
- Added resize cursors to make the available drag directions clear.

## Compatibility

This update retains the Linux x86_64 AppImage, stable desktop ID and built-in stable-release update channel. Existing `~/.appdepot` libraries, Server profiles and credentials are unchanged. An installed, user-owned v0.1.0 AppImage can offer this release through Settings → Updates. The owner's installed-app update remains to be tested by the owner; this release does not change local library schema or Server behavior.
