# App Depot Client v0.1.0

The first stable pre-1.0 Linux desktop distribution of App Depot Client.

## Highlights

- Browse self-hosted App Depot Servers, authenticate with a personal token and keep a useful offline catalog.
- Download File and Tree Artifacts with integrity verification, durable recovery and a prioritized queue.
- Launch declared NativePortableV1 Linux programs from writable local installations; manage, verify, repair and remove them locally.
- Install the x86_64 AppImage directly or through Gear Lever. The desktop can check future stable releases and update a supported user-owned AppImage in place.
- Use the new App Depot application icon in the desktop window and Linux application menu.

## Compatibility and limits

Linux x86_64 is the supported packaged target. Wayland and X11 are supported by the desktop; other Linux distributions still require local validation. Windows and macOS packages are not included. Native launch remains limited to the supported Server `NativePortableV1` contract. The Server never executes downloaded software. The AppImage does not change an existing `~/.appdepot` library or Secret Service credentials during installation. This is pre-1.0 software; back up a restorable local library before upgrading across future schema changes.
