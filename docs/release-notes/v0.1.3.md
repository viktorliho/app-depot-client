# App Depot Client v0.1.3

## Maintenance release

- Publishes the next stable Linux x86_64 AppImage to exercise the in-app update path from official v0.1.2 installations.
- Retains the GitHub release-asset redirect and checksum validation fix introduced in v0.1.2. No additional product functionality or local-library schema change is included.

## Upgrade

Official v0.1.2 AppImages can discover this release in **Settings → Updates & about**, download and verify it, then offer **Update and restart**. The actual update of an installed Gear Lever copy remains for the owner to validate; publication and isolated tests do not establish that result.

The AppImage identity, desktop entry, stable update source, `~/.appdepot` library, Server profiles and credentials are unchanged. No App Depot Server upgrade or library reset is required. Previously published releases and assets remain immutable.
